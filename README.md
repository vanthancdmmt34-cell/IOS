# LifeRivo

Học ngoại ngữ bằng tiếng Việt: Anh, Trung, Nhật, Hàn, Pháp. Luyện nói chấm từng từ, phỏng vấn thử và chứng nhận.

## Chạy

```bash
npm install
npm run build
npm start
```

Mặc định chạy tại http://127.0.0.1:8082. Biến môi trường xem trong `ecosystem.config.example.cjs`.

## Kiểm thử

```bash
npm test
```
