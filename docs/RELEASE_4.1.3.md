# PythonLab 4.1.3 — Personalized Learning

- The dashboard generates a 7-day study plan based on chapter competency and unpassed exercises.
- AI Tutor receives a server-validated chapter ID to focus support on the specific weak topic.
- Class reports add coverage, mastery, and chapters needing support for each student; visible only within the scope of classes the teacher is authorized to manage.
- The dashboard UI adds a 7-day study plan card and a shortcut to ask AI Tutor by chapter.

Note: The study plan is currently generated dynamically from current learning results; saving plan history and comparing start-of-week vs. end-of-week results will be added in the next phase to provide true longitudinal data.
